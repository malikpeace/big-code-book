Seventy years of coding in one hour

Nothing under Memento was invented for Memento. Every layer it stands on is between six and seventy years old, and each one was built by somebody solving their own problem. The only genuinely new thing in your company is who does the typing.

LAST TIME

One tap in Memento is a relay: phone, JavaScript, state, network, a rented server, the AI company, and back, then saved twice. The top of that map runs on the user's phone and the bottom runs on computers Memento pays rent for. The proxy exists so the secret key never rides along in the app.

Quick check

On the journey map, which stops run on somebody else's computer?
The edge function, Anthropic, and the Postgres database. Everything from finger to saved-on-phone runs on the user's own device, which the user already paid for.
What is the difference between a program and a process?
A program is the file of instructions sitting on a disk. A process is that program while it is running, loaded into memory, with a CPU walking through it.
Why does Memento have a proxy instead of calling the AI from the phone?
Because the call needs a secret key and a phone cannot keep a secret. Anything shipped to a user's device can be read by that user. The key lives in the server's environment instead.

The idea

Seventy years of programming is one move, repeated. Somebody does a horrible job by hand, once. Then they write a program that does that job, and nobody ever has to do it by hand again. The program that removes the horrible job is called an abstraction. Stack enough of them and you get 2026, where a founder who cannot write a for-loop ships a real app with real customers.

The first move was the biggest. In the 1940s and 1950s, a program was a physical thing: wires you moved, or cards with holes punched in them. Every instruction was a number, specific to one machine, and if you wanted the program on a different machine you wrote it again from scratch. This is machine code, and it is still what the CPU actually eats. Nobody writes it any more.

Then somebody wrote a program that read human-ish text and produced those numbers. That program is a compiler. Fortran arrived in 1957 and let scientists write formulas. C arrived in 1972 at Bell Labs and became the language operating systems are written in, which it still is, fifty-four years later. The compiler was written by hand in machine code once, and then never again. That is the shape of every layer that follows.

ANALOGY (TEMPORARY)

A building. You work on the ninth floor. Somebody poured the foundation in 1957, somebody framed the third floor in 1995, somebody put the lift in around 2010, and you have met none of them. You do not need to know how the plumbing works to use the tap. But the floors are real, they are load-bearing, and when the basement floods your ninth-floor carpet gets wet. That flood is what a bug at a lower layer feels like from up here.

The rest of the story, fast

In 1995 Netscape needed pages that could do something when you clicked. A man wrote JavaScript in about ten days. It was a rush job for a browser war and it is now the language your entire web app is written in, thirty-one years later. That is not unusual. Most of the load-bearing stuff in software was a rush job that nobody got around to replacing.

Next came the idea that code should be shared instead of sold: open source. Linux, Apache, and eventually everything. It means nobody starts from zero. In 2005 Linus Torvalds wrote Git in a couple of weeks because the Linux project lost access to its old tool. Git records every change to a folder of code so nothing is ever lost and two people can work on the same files. In 2008 GitHub put Git online and turned "pull request" into a verb. Your two agents commit through Git and push to GitHub every single day. Chapters 7 and 8 take that apart properly.

In 2006 Amazon started renting computers by the hour. That is the cloud, and it is the reason a solo founder can host anything at all. Before it, you bought a machine, put it in a room, and prayed. Two years later Apple opened the App Store and "an app" became the default shape of a software product, which is the shape you are rebuilding Memento into.

In 2009 Node.js let JavaScript run outside a browser, so the same language could write servers. In January 2010 npm shipped: a package manager, a way to download other people's JavaScript with one command. That one command is why a small project today pulls in hundreds of strangers' code. Chapter 19 covers what you are agreeing to when you install something.

In 2012 Microsoft released TypeScript: JavaScript with a proofreader that checks your work before anything runs. In 2013 Facebook open-sourced React, a framework for describing a screen as a function of your data instead of poking at the page by hand. In 2015 React Native did the same trick for phones, drawing real iOS and Android views from JavaScript. Expo grew on top as the standard toolkit. That combination is exactly what memento-native/ is.

Last floor. Firebase, from 2011, sold founders on not running a database server themselves. Supabase, founded in January 2020, did the open-source version on top of Postgres, the database the serious people already trusted. It is now what your accounts, sync, and billing sit on.

See it

The abstraction ladder, in one box. Three versions of the same job: add up a week of daily minutes. Level 0 is the machine's view, numbered slots and one finger. Level 1 wraps it in a name. Level 2 uses a wrapper somebody else already wrote. All three print the same number. Each one is shorter, and each one hides more from you.

// Level 0: the machine's view. Slots, an index, a running total. const slots = [20, 35, 0, 45, 15, 60, 10]; let total = 0; let i = 0; while (i < slots.length) { total = total + slots[i]; i = i + 1; } console.log("level 0:", total); // Level 1: same steps, given a name. Now it is a tool. function sumOf(list) { let t = 0; for (let n of list) t = t + n; return t; } console.log("level 1:", sumOf(slots)); // Level 2: somebody already wrote the loop. You describe the job. console.log("level 2:", slots.reduce((a, b) => a + b, 0));

Level 2 is where your agents write. Level 0 is what still runs. Nothing changed in the arithmetic, only in how much of it a human holds in their head.

Now in Memento

ANY APP: 1995, still running

The oldest way to build a web page is still the simplest: write HTML, list your script files in the order they should run, and the browser fetches and runs each one top to bottom. No build step, no tooling, no install. Every name a file defines becomes available to the files listed after it. Get the order wrong and something calls a name that does not exist yet.

MEMENTO: 1995, still running

The whole web app is loaded by a list of script tags in one file, in a hand-chosen order:

THE ALTERNATIVE, AND WHY MEMENTO CHOSE THIS

The web app could have used a bundler: a tool that reads all 38 JavaScript files, works out the order itself, squashes them into one file, and stamps a fresh address on it every build. Almost every professional web app does this. Memento does not, and there is no package.json in memento-app/ at all. The price of skipping it: the order is maintained by a human, the cache-busting version number is typed by hand in two places, and nothing checks either. What it bought: any file can be opened and read on its own, and the app runs by double-clicking a launcher. For a solo founder with two agents and no build engineer, that trade held up for a long time. The native rebuild takes the other road, which is why it has a lockfile and a CI robot.

WHERE TODAY'S ANALOGY BREAKS

Breaks when: you assume the floors are sealed and you never have to look down. Every abstraction leaks. A JavaScript number behaves oddly because of a 1985 floating-point standard. A CSS layout breaks on iOS because of how Safari counts a blurred element's size. An npm install pulls a stranger's code onto your machine. The ninth floor really does get wet. Real model: layers are contracts, not walls, and each one is honoured only until the case nobody thought about. The practical version for you: when something makes no sense at your layer, the answer is usually one floor down, and the fastest way to find it is to ask which layer is telling the lie.

RABBIT HOLE: what a compiler actually does

It reads your text into words, works out the grammar into a tree, checks the tree makes sense, then walks it producing instructions. JavaScript does not do this ahead of time. The engine in your browser reads the text, starts interpreting it immediately, and compiles the hot parts to machine code while the program is already running. That is why a JavaScript file needs no build step to work and why the same file runs on an iPhone and a Mac despite different chips: the engine on each does the translating. TypeScript, meanwhile, compiles to JavaScript and then throws all the type information away, because the browser never sees it. Chapter 21.
