# BIG CODE BOOK interactives

Include `interactives.css` once, then paste the one `<div>` and one `<script>` from a fragment into its chapter. Each fragment owns its state and scopes every lookup to its root element.

The SQL playground loads sql.js 1.13.0 from jsDelivr when the reader starts it. Its policy demo is deliberately labelled as a simulator because sql.js cannot enforce Postgres Row Level Security.
